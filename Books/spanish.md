## 2. Grammar

### Gender & Articles (Artículos de Género)

In Spanish, nouns have gender. The article changes depending on gender and whether singular or plural.

| | Singular | Plural |
|---|---|---|
| Masculine | **el** | **los** |
| Feminine | **la** | **las** |

**Rules:**
- Feminine words usually end in **-a**
- Feminine exceptions: words ending in **-ión**, **-dad**, **-tad**
- Everything else is usually masculine

*Examples: el coche, la mariposa, la universidad*

**Making words plural:**

| Ending | Rule | Example |
|---|---|---|
| Vowel | Add **-s** | plantas → plantas |
| Consonant | Add **-es** | reunión → reuniones |
| **-z** | Change **z → c**, add **-es** | lápiz → lápices |

### Adjectives (Adjetivos)

- In English, adjectives go **before** the noun: *The large house*
- In Spanish, adjectives go **after** the noun: *La casa grande*
- When the noun is plural, the adjective also becomes plural: *Las casas grandes*

| Español | English |
|---|---|
| Grande | Big |
| Pequeño | Small |
| Alto | Tall |
| Bajo | Short (person) |
| Corto | Short (thing) |
| Largo | Long |
| Delgado | Thin |
| Gordo | Fat |
| Bonito | Pretty |
| Feo | Ugly |

## 3. Verbs

### How to read the verb entries

Each verb shows a type label:

| Label | Meaning |
|---|---|
| Regular -AR / -ER / -IR | Follows standard conjugation pattern, no surprises |
| Irregular | Doesn't follow a standard pattern — needs memorising |
| Stem-change E→IE | Vowel in the stem changes in all forms except nosotros/vosotros |
| Stem-change O→UE | Same, but O changes to UE |
| Stem-change E→I | Same, but E changes to I |
| Reflexive | Action done to yourself — needs a reflexive pronoun (me/te/se/nos/os/se) |

### Gustar — To Like
> **Type:** Irregular | Reverse construction (the thing liked is the subject)

Two forms only — depends on whether the thing liked is singular or plural:

| Person | Singular (one thing) | Plural (multiple things) |
|---|---|---|
| Me (I) | Me gusta | Me gustan |
| Te (you) | Te gusta | Te gustan |
| Le (he/she) | Le gusta | Le gustan |
| Nos (we) | Nos gusta | Nos gustan |
| Os (you pl) | Os gusta | Os gustan |
| Les (they) | Les gusta | Les gustan |

*Me gusta el chocolate. / Nos gustan los animales.*
To negate, add **no** before the pronoun: *No te gusta cantar.*

### Stem-Changing Verbs (Verbos de cambio vocálico)

Some verbs change their stem vowel in the present tense. The change applies to all forms **except nosotros and vosotros**.

**3 main types:**

| Type | Example |
|---|---|
| E → IE | Cerrar → Yo cierro |
| O → UE | Mover → Yo muevo |
| E → I | Repetir → Yo repito |

### Telling the Time (La Hora)

*¿Qué hora es?* — What time is it?

| Rule | Usage |
|---|---|
| **Son las** + number | Used for 2–12 o'clock |
| **Es la** una | Used for 1 o'clock only |
| **en punto** | O'clock (precisely) |

**Quarter hours:**

| Spanish | English |
|---|---|
| y cuarto | Quarter past |
| y media | Half past |
| menos cuarto | Quarter to |

**AM/PM:**
- *Son las seis de la mañana* — 6am
- *Son las seis de la tarde* — 6pm

*Examples: Son las cinco y cuarto (5:15). Son las dos y media (2:30). Son las ocho menos cuarto (7:45).*
